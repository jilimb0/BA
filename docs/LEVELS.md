# Development Methodology - Levels 01-06

## Level 01 - Idea & Context
**Goal:** Define the problem, users, and success criteria for the business analyzer.

## Level 02 - Architecture & Design
**Goal:** Document the system architecture (Hono server + analyzer module + static frontend).

## Level 03 - Implementation (Skeleton)
**Goal:** Working pipeline: GeoJSON upload → processing → CSV → browser UI.

## Level 04 - Quality
**Standard:** Biome lint, TypeScript strict, 27+ tests, coverage thresholds.
**Goal:** Verified data transformation, error handling, input validation.

## Level 05 - Releases
**Goal:** Versioned releases with CHANGELOG, automated CI/CD.

## Level 06 - Deploy
**Goal:** Docker Compose deployment with health checks.
