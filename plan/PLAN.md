# BA (Business Analyzer) — План развития модуля гео-аналитики

> **Мировой бенчмарк:** Causal / Baremetrics / Location Intelligence Tools  
> **Суть продукта:** Инструмент анализа гео-данных OpenStreetMap, фильтрации и оценки коммерческих POI для выбора локаций бизнеса.  
> **Текущий статус:** Hono 4 + Zod 4 + TypeScript, Biome, Vitest (49 тестов), Leaflet карта, алгоритмы плотности Haversine & SpatialGrid, скоринг локаций 0-100, HTML/PDF экспорт, встраиваемый виджет `/widget` для C&TLab, Docker Compose.

---

## 1. Технический бэклог доработок (Technical Debt & Features)

- [x] **Увеличить тестовое покрытие парсеров GeoJSON с 2 до 15+ тестов** *(Реализовано: 49 тестов в Vitest, включая валидацию Zod 4 схем GeoJSON FeatureCollection и Overpass элементов)*
- [x] **Добавить автоматический расчет плотности конкурентов в радиусе 500м / 1000м** *(Реализовано: SpatialGrid + Haversine с расчетом конкурентов и синергетических POI)*
- [x] **Экспорт аналитического отчета по локации в интерактивный HTML/PDF** *(Реализовано: модуль генерации отчетов и endpoint `GET /api/report?osm_id=...`)*

---

## 2. Дизайн и UX/UI бэклог

- [x] **Интерактивная карта с визуализацией плотности бизнесов** *(Реализовано: Leaflet с цветовой дифференциацией 12 категорий, попапами и зумом)*
- [x] **Фильтры по категориям (кофейни, салоны, аптеки, пекарни)** *(Реализовано: каскадные фильтры групп и категорий с динамическим подсчетом)*
- [x] **Табличный просмотрщик с сортировкой по плотности и рейтингу** *(Реализовано: сортировка по Name, Group, Category, Density 500m, Score)*

---

## 3. Модель монетизации и биллинг

* **Тарифная сетка:** B2B Pay-per-report ($19 за отчет по локации) или модуль внутри экосистемы C&TLab
* **Платежный шлюз:** Stripe / CloudPayments / Crypto
* **Триггер пейволла:** Ограничение функционала после триала, плашка отчета с маркировкой B2B-тарифа
