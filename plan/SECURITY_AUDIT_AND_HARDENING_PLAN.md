# План аудита и устранения уязвимостей безопасности: BA (Business Analyzer)

> **Текущий скор безопасности:** 45 / 100 (🚨 Критический уровень риска)  
> **Дата аудита:** Октябрь 2026  
> **Статус:** Требуется немедленное исправление P0  

---

## 1. Обнаруженные уязвимости

### [P0] Неаутентифицированный запуск тяжелых процессов и DoS (Resource Exhaustion)
* **Файл:** `src/server.ts` (строки 88–147)
* **Механика проблемы:**
  Эндпоинт `app.post('/generate')` позволяет любому анонимному пользователю загрузить файл размером до 50MB и инициирует выполнение дочернего процесса Node.js:
  ```typescript
  const child = spawn('npx', ['tsx', 'src/process.ts', `--input=${inputPath}`, `--output=${outputPath}`, ...]);
  ```
  При этом результаты записываются прямо в корень проекта (`businesses.csv` и `businesses_summary.csv`), перезаписывая данные для всех пользователей.
* **Потенциальный ущерб:**
  - Отказ в обслуживании (Denial of Service) через параллельную отправку тяжелых файлов (переполнение диска, 100% утилизация CPU/памяти).
  - Нарушение целостности данных: несанкционированная подмена рабочих аналитических датасетов.

### [P1] Неограниченный CORS (Wildcard Origins)
* **Файл:** `src/server.ts` (строка 30)
* **Механика проблемы:**
  Вызов `app.use('*', cors())` открывает доступ ко всем эндпоинтам с любых внешних доменов (`Access-Control-Allow-Origin: *`).

### [P1] Публичная раздача сырых датасетов
* **Файл:** `src/server.ts` (строки 58–60)
* **Механика проблемы:**
  Файлы `businesses.csv` и `businesses_summary.csv` отдаются статически любому посетителю без авторизации, что открывает коммерческие собранные данные для прямого парсинга конкурентами.

## 2. Пошаговый план устранения (Hardening Plan)

- [ ] **Шаг 1 (P0): Закрыть роут `/generate` строгой аутентификацией**
  - Ввести обязательную проверку Bearer токена администратора (`ADMIN_API_KEY`) через middleware Hono.
  - При отсутствии или несовпадении ключа немедленно возвращать `401 Unauthorized` до чтения тела запроса и создания временных файлов.

- [ ] **Шаг 2 (P0): Изоляция генерации и предотвращение переполнения диска**
  - Ограничить размер загружаемого файла разумным пределом (например, 10–15MB).
  - Выполнять генерацию в изолированном пространстве (staging), проверяя валидность GeoJSON перед перезаписью продуктового файла.
  - Добавить защиту от одновременных запусков (mutex / single worker queue).

- [ ] **Шаг 3 (P1): Настройка CORS**
  - Заменить wildcard `cors()` на белый список доверенных источников (домен портфолио, локальный фронтенд).

- [ ] **Шаг 4 (P1): Контроль доступа к датасетам**
  - Исключить прямое скачивание `businesses.csv` без авторизации, если эти данные являются коммерческой ценностью.
